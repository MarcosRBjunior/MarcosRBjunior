Backend-focused developer building REST APIs and full-stack projects, with a strong focus on **automated testing** — unit, integration and end-to-end — and CI/CD pipelines.

Currently deepening my skills through hands-on projects: a bookstore API with a full automated-testing pyramid, a library management API with MongoDB, and a decentralized voting application built with React and Solidity.

I care about writing code that's tested, documented and easy to reason about — not just code that runs.

## `✦ projects`

<br>

**Livraria API** &nbsp;·&nbsp; [repo ↗](https://github.com/MarcosRBjunior/Teste_E2E)

- REST API for a bookstore — CRUD for authors, publishers and books
- Sale registration with payment-method discounts, stock checks and publisher email notifications
- Full automated-testing pyramid (unit, integration, e2e) using Node's native test runner
- CI/CD pipeline configured with GitHub Actions

**BibliotecaCrud** &nbsp;·&nbsp; [repo ↗](https://github.com/MarcosRBjunior/BibliotecaCrud)

- REST API for managing books and authors with Node.js, Express and MongoDB/Mongoose
- Layered architecture — routes, controllers and models

**Projeto-Web3** &nbsp;·&nbsp; [repo ↗](https://github.com/MarcosRBjunior/Projeto-Web3)

- On-chain voting DApp built with React, Vite and Wagmi
- Wallet-authenticated voting via Ethereum smart contracts
